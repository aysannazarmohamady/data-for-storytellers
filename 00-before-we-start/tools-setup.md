# راهنمای نصب و آماده‌سازی ابزارها

این فایل کمک می‌کند قبل از شروع فصل‌های عملی، ابزارهای لازم را آماده کنی. اگر هیچ تجربه‌ای با نصب ابزارهای برنامه‌نویسی نداری، نگران نباش؛ این راهنما برای شروع ساده نوشته شده است.

لازم نیست همه ابزارها را همین اول نصب کنی. برای فصل‌های اول، مرورگر و Google Sheets کافی است. Python و ابزارهای کدنویسی از فصل‌های کم‌کد به بعد لازم می‌شوند.

## ۱. مرورگر

یک مرورگر به‌روز نصب داشته باش:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox

اگر همین حالا یکی از این‌ها را داری و به‌روز است، همین کافی است.

برای اطمینان، مرورگر را باز کن و وارد چند سایت معمولی شو. اگر صفحه‌ها درست باز می‌شوند و امکان ورود به حساب Google را داری، این بخش آماده است.

---

## ۲. حساب Google

برای کار با Google Sheets و Google Colab بهتر است یک حساب Google داشته باشی.

با این حساب می‌توانی:

- فایل‌های CSV و Excel را در Google Sheets باز کنی.
- تمرین‌های ساده را بدون نصب برنامه اضافه انجام بدهی.
- کدهای Python را در Google Colab اجرا کنی.

اگر به هر دلیل نمی‌خواهی از Google استفاده کنی، می‌توانی از Excel یا LibreOffice Calc برای صفحه‌گسترده و از Python نصب‌شده روی سیستم برای کدنویسی استفاده کنی.

---

## ۳. ابزار صفحه‌گسترده

برای شروع، یکی از این گزینه‌ها کافی است:

- **Google Sheets:** رایگان، آنلاین، مناسب برای شروع.
- **Microsoft Excel:** قدرتمند و آشنا برای خیلی از کاربران.
- **LibreOffice Calc:** رایگان و آفلاین.

در فصل‌های اول، با فایل‌هایی مثل CSV و Excel کار می‌کنیم. اگر بتوانی یک فایل جدولی را باز کنی، ستون‌ها را ببینی، فیلتر بزنی و مرتب‌سازی انجام بدهی، آماده‌ای.

### تست سریع

یک صفحه جدید بساز و این جدول کوچک را در آن وارد کن:

| city | year | value |
|------|------|-------|
| Tehran | 2022 | 120 |
| Tehran | 2023 | 145 |
| Shiraz | 2022 | 80 |
| Shiraz | 2023 | 95 |

بعد ستون `value` را از بزرگ به کوچک مرتب کن. اگر انجام شد، بخش صفحه‌گسترده آماده است.

## ۴. ابزارهای بصری‌سازی بدون کد

برای ساخت نمودارهای ساده و قابل انتشار، دو ابزار خیلی مفید هستند:

- **Datawrapper:** مناسب برای نمودارهای خبری، نقشه و جدول‌های تمیز.
- **Flourish:** مناسب برای نمودارهای تعاملی و روایت‌های بصری.

لازم نیست در هر دو حساب بسازی، اما پیشنهاد من این است:

1. اول با Datawrapper شروع کن.
2. بعد اگر خواستی نمودارهای تعاملی‌تر بسازی، Flourish را هم امتحان کن.

### تست سریع Datawrapper

1. وارد سایت Datawrapper شو.
2. یک حساب رایگان بساز.
3. یک نمودار ستونی ساده با همان جدول تستی بخش قبل بساز.
4. عنوان نمودار را تغییر بده و خروجی را پیش‌نمایش کن.

همین برای شروع کافی است.

## ۵. Visual Studio Code

Visual Studio Code یا VS Code یک ویرایشگر رایگان است. با آن می‌توانی فایل‌های متنی، Markdown، CSV و کدهای Python را راحت‌تر ببینی و ویرایش کنی.

بعد از نصب VS Code، این افزونه‌ها مفید هستند:

- Python
- Jupyter
- Markdown Preview

اگر نمی‌خواهی فعلاً چیزی نصب کنی، می‌توانی فصل‌های اول را بدون VS Code هم جلو بروی. از فصل ۰۳ به بعد داشتنش کار را راحت‌تر می‌کند.

## ۶. Python

Python زبانی است که در این دوره برای تحلیل ساده داده استفاده می‌کنیم. لازم نیست همه زبان را یاد بگیری. فقط چند دستور پایه و چند ابزار مهم کافی است.

دو مسیر داری:

### مسیر ساده‌تر: Google Colab

اگر نمی‌خواهی Python را روی کامپیوترت نصب کنی، از Google Colab استفاده کن. Colab داخل مرورگر اجرا می‌شود و خیلی از کتابخانه‌های لازم را از قبل دارد.

برای شروع:

1. وارد Google Colab شو.
2. یک Notebook جدید بساز.
3. این خط را در یک سلول بنویس و اجرا کن:

```python
print("Hello data!")
```

اگر پیام `Hello data!` را دیدی، آماده‌ای.

### مسیر کامل‌تر: نصب روی سیستم

اگر می‌خواهی Python را روی سیستم خودت داشته باشی، یکی از این روش‌ها را انتخاب کن.

#### Windows

1. Python را از سایت رسمی python.org نصب کن.
2. هنگام نصب، گزینه **Add Python to PATH** را فعال کن.
3. بعد از نصب، Command Prompt یا PowerShell را باز کن.
4. این دستور را بزن:

```bash
python --version
```

اگر نسخه Python را دیدی، نصب درست انجام شده است.

#### macOS

در macOS معمولاً بهتر است Python جدید را جدا نصب کنی.

راه ساده:

1. Python را از سایت رسمی python.org نصب کن.
2. Terminal را باز کن.
3. این دستور را بزن:

```bash
python3 --version
```

اگر نسخه Python را دیدی، آماده‌ای.

#### Linux

در خیلی از توزیع‌های Linux، Python از قبل نصب است.

Terminal را باز کن و بزن:

```bash
python3 --version
```

اگر نصب نبود، با ابزار نصب توزیع خودت Python را نصب کن.

## ۷. نصب کتابخانه‌های Python

برای فصل‌های کم‌کد، این کتابخانه‌ها را لازم داریم:

- pandas برای کار با جدول‌ها
- matplotlib برای نمودارهای ساده
- jupyter برای Notebookها
- openpyxl برای خواندن و نوشتن فایل‌های Excel

اگر از Google Colab استفاده می‌کنی، معمولاً pandas و matplotlib از قبل آماده‌اند. اگر Python را روی سیستم نصب کرده‌ای، در Terminal یا Command Prompt این دستور را اجرا کن:

```bash
pip install pandas matplotlib jupyter openpyxl
```

در macOS و Linux ممکن است لازم باشد بنویسی:

```bash
python3 -m pip install pandas matplotlib jupyter openpyxl
```

### تست سریع

بعد از نصب، این دستور را اجرا کن:

```bash
python3 -c "import pandas as pd; print(pd.__version__)"
```

در Windows ممکن است این نسخه بهتر جواب بدهد:

```bash
python -c "import pandas as pd; print(pd.__version__)"
```

اگر یک عدد نسخه دیدی، pandas درست نصب شده است.

## ۸. Jupyter Notebook

Notebook محیطی است که در آن می‌توانی کد، توضیح و خروجی را کنار هم داشته باشی. برای یادگیری تحلیل داده خیلی مناسب است.

اگر کتابخانه jupyter را نصب کرده‌ای، با این دستور اجرا می‌شود:

```bash
jupyter notebook
```

بعد از اجرا، یک صفحه در مرورگر باز می‌شود. از آنجا می‌توانی Notebook جدید بسازی.

اگر اجرای Jupyter برایت دردسر داشت، فعلاً از Google Colab استفاده کن. برای این دوره کاملاً کافی است.

## ۹. GitHub

GitHub جایی است که این ریپو و فایل‌هایش نگهداری می‌شوند. برای خواندن محتوا لازم نیست حتماً Git بلد باشی. اما اگر می‌خواهی تمرین‌ها را دانلود کنی یا تغییرات خودت را نگه داری، داشتن حساب GitHub مفید است.

برای شروع فقط این‌ها کافی است:

- بتوانی فایل‌های ریپو را در مرورگر ببینی.
- بتوانی یک فایل را دانلود کنی.
- اگر خواستی، کل ریپو را با گزینه Download ZIP بگیری.

یادگیری Git را می‌توانی بعداً اضافه کنی. در این دوره، اولویت با فهم داده و روایت است.

## ۱۰. ابزار هوش مصنوعی

برای فصل‌های مربوط به هوش مصنوعی، به یک ابزار مدل زبانی نیاز داری. گزینه‌هایی مثل ChatGPT یا ابزارهای مشابه قابل استفاده‌اند.

در استفاده از این ابزارها چند نکته را جدی بگیر:

- اطلاعات شخصی، محرمانه یا حساس را بدون فکر وارد نکن.
- خروجی مدل را منبع قطعی حساب نکن.
- برای ادعاهای مهم، منبع مستقل پیدا کن.
- اگر مدل عدد، نقل‌قول یا منبع داد، حتماً بررسی کن.
- از مدل بخواه عدم‌قطعیت‌ها و فرض‌هایش را بگوید.

### تست سریع پرامپت

این پرامپت را امتحان کن:

```text
من یک روزنامه‌نگارم و می‌خواهم درباره افزایش اجاره‌خانه گزارش بنویسم.
۵ سوال داده‌محور پیشنهاد بده که بتوانم با داده‌های عمومی بررسی کنم.
برای هر سوال بگو چه نوع داده‌ای لازم دارم.
```

اگر خروجی گرفتی و توانستی کیفیتش را نقد کنی، آماده‌ای.

## ۱۱. پوشه کاری پیشنهادی

برای اینکه فایل‌ها گم نشوند، روی کامپیوترت یک پوشه برای تمرین‌ها بساز. مثلاً:

```text
data-for-storytellers-practice/
├── data/
├── notebooks/
├── charts/
└── notes/
```

پیشنهاد:

- فایل‌های خام را در پوشه `data` نگه دار.
- Notebookها یا فایل‌های Python را در `notebooks` بگذار.
- خروجی نمودارها را در `charts` ذخیره کن.
- ایده‌ها، منابع و سوال‌ها را در `notes` بنویس.

برای شروع دوره، هیچ مشکلی نباید تو را متوقف کند. همیشه یک مسیر ساده‌تر وجود دارد.
